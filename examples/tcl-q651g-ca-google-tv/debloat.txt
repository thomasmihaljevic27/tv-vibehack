# TCL 50Q651G-CA, 2024 Q6/Q65 series, Canada (device G10, product G10_4K_US_NF, boot product S551G)
# Android 12 (Google TV), firmware STT2.230203.001, software V8-R75PT01-LF1V499
# Same platform and build as examples/tcl-g10-google-tv, so the Canadian model reports a US product name.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-q651g-ca-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-q651g-ca-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Windows: tools\restore.ps1 -TvHost <tv ip> examples\tcl-q651g-ca-google-tv\debloat.txt -Stock com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair and com.tcl.systemserver too.
# Also kept: com.tcl.initsetup (channel installation service), com.tcl.useragreement and
# com.tcl.providers.config (queried by other TCL apps), com.tcl.factory.view (service menu).
# Already disabled at the factory: tv.samba.ssm.ui (Samba TV ACR). Unlike the G10, com.tcl.logkit and
# com.tcl.ttvs ship ENABLED here, so they are listed below.
#
# Known quirks on this firmware:
# - Firmware updates come through Google Play Services (com.google.android.gms/.update.SystemUpdateService),
#   not a TCL package, so no line here blocks them. com.tcl.UpdatePeripheral only updates TCL soundbars.
# - Disabling dreamx (Google TV's ambient mode) leaves screensaver_components pointing at it. Switch to
#   the launcher's Art screensaver, its ambient-mode replacement (or .ClockDream; the AOSP fallback is
#   com.android.dreams.basic/.Colors), and optionally a 5-minute idle (the stock value here was 10):
#   tools/tv.py 'settings put secure screensaver_components com.gathin.tvhome/.ArtDream'
#   tools/tv.py 'settings put system screen_off_timeout 300000'
# - The TV rebooted overnight once during testing; setupwraith and every other disable stayed in place.
# - screencap writes an empty file while Live TV/HDMI is on screen. Press Home first.
# - Live TV (com.tcl.tv) still opens and plays with com.tcl.ttvs disabled.
# - The Google TV promo banner is drawn by launcherx itself, so only launcher/ removes it.
# - With launcherx disabled, Home opens setupwraith's RecoveryActivity (a black screen, HOME priority 1)
#   instead of a third-party launcher (priority 0); set-home-activity and the HOME role don't override
#   it. That's why setupwraith is listed below. Run launcher/build-and-install after applying this list.
# - The TV dropped off Wi-Fi/ADB for about a minute twice during the session (no reboot). Wait and retry.
# - The remote's gear button sends KEYCODE_NOTIFICATION, which opens Google TV's dashboard panel inside
#   launcherx; with launcherx disabled it does nothing. launcher/ catches it with an accessibility
#   service (GearKeyService) that build-and-install enables. TCL's TclAppBoot blocks that service until
#   the launcher has the APP_AUTO_START app-op: cmd appops set com.gathin.tvhome APP_AUTO_START allow
# - The remote is Bluetooth (BT_RC813_MG). `input keyevent` and sendevent can't stand in for it when
#   testing the gear button: injected keys skip accessibility filters, and /dev/input is SELinux-locked.
